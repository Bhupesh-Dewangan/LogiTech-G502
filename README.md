## Overview

This project showcases a polished product experience with sections for:
- Hero introduction
- Product highlights
- Key features
- Technical specifications
- Contact information

The site uses smooth transitions and a responsive layout to present the product in an engaging way.

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion (via the Motion library)
- React Icons
- ESLint

## Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Then open your browser at:

```text
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## Scripts

- npm run dev - Start the Vite development server
- npm run build - Build the app for production
- npm run preview - Preview the production build locally
